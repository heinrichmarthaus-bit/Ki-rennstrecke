# KI-Rennstrecke

Zeichne eine Rennstrecke. Danach lernen 50 KI-Autos pro Generation per Neuroevolution, die Strecke möglichst schnell zu fahren.

- 3 Sensoren pro Auto (links 45°, geradeaus, rechts 45°), die nur Wände erkennen und keine anderen Autos
- Wandkontakt bedeutet: Das Auto ist tot
- Token-System als Belohnung: Checkpoints, Tempo-Bonus, Rundenbonus und Zeitbonus; Abzug für Crash oder Stillstand
- Genetischer Algorithmus: Elite, Turnier-Auswahl, Crossover, Mutation

Einfach `index.html` im Browser öffnen. Es wird keine Installation benötigt.
